## science-edu-activity 技能更新

### 用户输入
用户分享了一段关于科学传播/科普的理念，要求融入到 science-edu-activity 技能中。

### 评估结果
| 理念 | 采纳？ | 原因 |
|------|--------|------|
| 第一次转化（问题逻辑、挂钩点、天钩类比） | ✅ | 现有框架缺少"公众先关心什么"这个入口 |
| 第二次转化（过程叙事、人的挣扎、意外之美） | ✅ | 现有输出偏"知识正确"，缺少故事素材 |
| 第三次转化之"主动露怯" | ✅ | CoE 体系没要求主动披露局限，值得加 |
| 第三次转化之"共建生态" | ❌ | 已被 UDL×SDT + 元认知完整覆盖，会冗余 |
| "参与接口"（动手实验） | ❌ | Activity Matching + UDL 已覆盖 |
| 知识的诅咒（三版本） | ✅ | 非常实用的自检机制 |

### 具体改动
1. **Phase 2 步骤2**：新增「问题逻辑转换」，要求回答三个问题：像什么？有什么用？跟我有什么关系？
2. **Phase 2 步骤5**：新增「科学叙事素材」收集（人的挣扎、意外之美、当代声音）
3. **准确率标注**：新增 ⚠️ 已知局限标注，要求主动披露技术边界
4. **UDL 多元参与**：新增「开放性问题设计」作为参与接口
5. **Output Format**：新增「分层沟通设计」检查点（一句话/一段话/详细版）
6. **QA Checklist**：新增6项检查点覆盖以上所有改动
7. **新建 README.md / README_zh.md**
