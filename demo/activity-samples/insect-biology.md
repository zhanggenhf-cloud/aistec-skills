# 昆虫观察家

## 基本信息
- **适用年龄**: 7-11岁
- **活动时长**: 90分钟（含户外时间）
- **参与人数**: 12-20人
- **学科领域**: 生物
- **核心概念**: 昆虫的身体结构和特征

## 活动摘要
在户外环境中观察和捕捉昆虫，学习使用观察工具，了解昆虫的基本特征，培养自然观察能力和科学记录习惯。

**安全提醒**: 不捕捉未知有毒昆虫；户外活动注意防晒防蚊；返回后彻底洗手

## 学习目标
1. 识别昆虫的基本特征（六条腿、身体分三部分、通常有翅膀）
2. 使用放大镜进行细致观察
3. 用图画和文字记录观察结果

## 活动流程

### 阶段一：引入 (15分钟)
**室内准备**
- 展示昆虫标本和图片
- 讲解昆虫的定义特征
- 介绍观察工具使用方法（放大镜、观察盒）
- 分发观察记录表

### 阶段二：探索 (45分钟)
**户外观察活动**

**分组任务**:
- A组：草地寻找（蚱蜢、蝴蝶、蚂蚁）
- B组：树木寻找（蝉、甲虫、毛毛虫）
- C组：花坛寻找（蜜蜂、瓢虫、蜻蜓）

**观察记录要求**:
1. 发现什么昆虫？
2. 它在做什么？
3. 画出它的样子
4. 标注身体各部分

**观察记录表**:
| 发现地点 | 昆虫名称 | 在做什么 | 身体特征 | 简笔画 |
|---------|---------|---------|---------|--------|
| | | | | |

### 阶段三：讨论 (20分钟)
**室内分享**

**小组汇报**:
每组分享最有趣的发现

**引导问题**:
1. "你发现的昆虫有什么共同特征？"
2. "昆虫的身体可以分成哪三部分？"
3. "为什么有些昆虫有翅膀，有些没有？"

**概念总结**:
- 昆虫身体：头、胸、腹
- 六条腿都长在胸部
- 昆虫是地球上种类最多的动物

### 阶段四：应用 (10分钟)
**拓展思考**

**蜘蛛是昆虫吗？**
对比蜘蛛和昆虫的特征，理解分类依据

**保护昆虫**:
讨论昆虫在生态系统中的作用，强调观察后放生

**观察作业**:
回家后在家附近寻找3种不同的昆虫，拍照或画下来

## 材料清单
| 材料名称 | 数量 | 规格/要求 |
|---------|------|----------|
| 放大镜 | 20个 | 5倍放大 |
| 观察盒 | 20个 | 带透气孔 |

| 彩色笔 | 10盒 | 12色 |
| 捕虫网 | 5个 | 儿童安全型 |

## 场地要求
- **室内**: 教室用于准备和总结（20-30人容量）
- **户外**: 校园花园/公园，有草地、树木、花坛
- **时间**: 晴朗天气，上午9-11点（昆虫活跃时段）

## 人员配置
- **主讲老师**: 1人（负责讲解和安全）
- **助教**: 2人（分组带领户外观察）

## 评估要点
- [ ] 能正确说出昆虫的3个基本特征
- [ ] 观察记录完整（有图画和文字）
- [ ] 能区分昆虫和非昆虫（如蜘蛛）
- [ ] 表现出对自然的尊重和好奇心

## 应急预案
- **如果下雨**: 改为室内昆虫标本观察+昆虫纪录片观看
- **如果找不到昆虫**: 提前在观察区域放置诱虫装置（香蕉皮、糖水）
- **如果有人被昆虫叮咬**: 立即处理，准备清凉油、湿巾
