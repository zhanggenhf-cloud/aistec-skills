# 日食与月食

## 基本信息
- **适用年龄**: 9-14岁
- **活动时长**: 75分钟
- **参与人数**: 20-40人
- **学科领域**: 天文
- **核心概念**: 日食和月食的形成原理（天体位置关系）

## 活动摘要
通过角色扮演和模型演示，理解太阳、地球、月球的相对位置如何导致日食和月食，澄清常见误解。

## 学习目标
1. 解释日食和月食的形成原因
2. 区分日全食、日偏食、日环食
3. 纠正"天狗吃月亮"等迷信说法
4. 预测下一次可见的日食/月食时间

## 活动流程

### 阶段一：引入 (12分钟)
播放日全食视频（贝利珠、日冕），提问："日食是怎么发生的？月球真的在吃太阳吗？"

展示古代对日食的解释（神话 vs 科学），引出科学解释的重要性。

### 阶段二：探索 (30分钟)
**角色扮演活动：天体运行模拟**

**准备**: 
- 太阳（直径60cm黄色圆盘）- 1人
- 地球（直径15cm蓝色球）- 1人  
- 月球（直径8cm灰色球）- 1人

**模拟1：日食形成**
1. 月球站在太阳和地球之间
2. 月球的影子投射到地球上
3. 位于影子区域的"地球人"看不到太阳

**模拟2：月食形成**
1. 地球站在太阳和月球之间
2. 地球的影子投射到月球上
3. 月球进入地球影子，变暗变红

**小组讨论记录**:
| 现象 | 天体排列顺序 | 哪个天体变暗 | 发生频率 |
|-----|-------------|-------------|---------|
| 日食 | | | |
| 月食 | | | |

### 阶段三：讨论 (20分钟)
**澄清误解**

**常见误解 1**: "日食每个月都会发生"
- 解释：月球轨道与地球轨道有5°倾斜，不是每次新月都遮挡太阳

**常见误解 2**: "月食比日食更常见"
- 解释：实际上月食更频繁，但可见范围不同

**常见误解 3**: "看日食会瞎，看月食没事"
- 强调：直视太阳永远危险，日食时更需专业防护

**安全观看日食的方法**:
- 日食眼镜（不是普通墨镜）
- 针孔投影法
- 望远镜投影法

### 阶段四：应用 (13分钟)
**未来预测**

查阅天文年历，找出：
- 下一次月食的时间
- 下一次中国可见日食的时间

**拓展思考**:
- 如果在月球上看地球，会有"地食"吗？
- 其他行星上能看到日食吗？（如木星卫星遮挡太阳）

## 场地要求
- 需要能进行角色扮演活动的空间
- 能完全遮光演示投影（部分环节）

## 评估方式
- 能画出日食和月食的天体位置示意图
- 能解释为什么不是每个月都有日食
- 能说出安全观看日食的方法

## 注意事项
**重要安全警告**: 
必须强调直视太阳的危害，即使日食时太阳被遮挡大部分，剩余光弧仍足以损伤视网膜。
