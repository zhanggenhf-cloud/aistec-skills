# 彩虹的秘密

## 基本信息
- **适用年龄**: 8-12岁
- **活动时长**: 60分钟
- **参与人数**: 20-30人
- **学科领域**: 物理/光学
- **核心概念**: 光的色散现象

## 活动摘要
通过三棱镜实验和喷雾活动，让参与者观察和理解白光如何分解成七色光谱，探索彩虹形成的科学原理。

**所需材料**: 三棱镜、手电筒、喷水壶、白纸、彩色笔
**安全提醒**: 使用手电筒时注意光线不要直射眼睛

## 学习目标
完成本活动后，参与者能够：
1. 描述白光通过三棱镜后分解成彩色光的现象
2. 解释彩虹形成的必要条件（阳光+水滴+观察角度）
3. 举例说明生活中的色散现象

## 背景知识
### 科学原理
白光实际上是由不同波长的色光混合而成。当白光进入三棱镜时，不同波长的光折射角度不同，红光折射最少，紫光折射最多，因此分解成光谱。

彩虹是阳光经过空气中的水滴时发生折射、反射和再次折射形成的自然现象。

### 现实应用
- 钻石的璀璨光芒
- 肥皂泡的彩色
- CD 表面的彩虹色

## 活动流程

### 阶段一：引入 (10分钟)
**目标**: 激发兴趣，建立与生活的连接

**内容**:
1. 展示彩虹图片，提问："你见过彩虹吗？在哪里？什么时候？"
2. 播放彩虹形成过程短视频
3. 提出问题："彩虹是怎么形成的？我们能自己制造彩虹吗？"

**话术建议**:
> "今天我们要成为光的魔法师，解开彩虹的秘密！"

### 阶段二：探索 (25分钟)
**目标**: 动手操作，观察光的色散现象

**实验1：三棱镜分光**
1. 每组发放三棱镜、手电筒、白纸
2. 将三棱镜放在阳光下（或手电筒前）
3. 在白纸上观察彩色光谱
4. 记录观察到的颜色顺序

**实验2：喷雾造彩虹**
1. 背对阳光站立
2. 用喷水壶向空中喷雾
3. 寻找观察彩虹的最佳角度

**观察记录表**:
| 实验 | 观察到的现象 | 颜色顺序 |
|-----|-------------|---------|
| 三棱镜 | | |
| 喷雾 | | |

### 阶段三：讨论 (15分钟)
**目标**: 理解原理，建构知识

**引导问题**:
1. "你观察到了几种颜色？顺序是什么？"
2. "为什么白光会变成彩色？"
3. "为什么彩虹总是出现在雨后的天空？"

**概念讲解**:
用简单比喻解释：光就像一群不同速度的小朋友跑步，遇到障碍物（三棱镜/水滴）时，速度不同的小朋友分开跑了。

### 阶段四：应用 (10分钟)
**目标**: 延伸思考，连接生活

**拓展活动**:
1. "寻找生活中的彩虹"——分享见过的色散现象
2. "如果世界上没有光会怎样？"小组讨论
3. 布置观察作业：雨后寻找彩虹，记录时间地点

**进阶挑战**:
> "你能用身边的材料（如CD、肥皂水）制造彩虹吗？回家试试看！"

## 场地要求
- **空间大小**: 教室或活动室，能容纳30人分组活动
