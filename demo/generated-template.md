# 科普教育活动方案标准模板

## 模板元数据
- **版本**: 1.0.0
- **生成来源**: 基于5个活动方案分析（物理、化学、生物、天文、环境）
- **适用场景**: 科技馆/学校/科普中心
- **典型时长**: 45-90分钟（默认 60分钟）
- **典型人数**: 15-30人
- **生成日期**: 2026-04-02

---

## 结构规范

### 必须章节（出现频率 ≥ 100%，不可省略）
1. 方案标题
2. 基本信息
3. 学习目标
4. 活动流程
5. 材料清单
6. 安全提示
7. 评估方式

### 推荐章节（出现频率 50-80%，建议保留）
1. 活动摘要
2. 背景知识/科学原理
3. 场地要求
4. 应急预案

### 可选章节（出现频率 < 50%，按需添加）
1. 人员配置
2. 参考资料

## 各章节详细规范

### 1. 方案标题
- **要求**: 简洁有力，体现科学概念和活动特点
- **格式**: `# [标题]`
- **示例**: `# 彩虹的秘密` `# 火山喷发实验`

### 2. 基本信息
**格式**:
```markdown
## 基本信息
- **适用年龄**: [年龄范围，如 8-12岁]
- **活动时长**: [时长，如 60分钟]
- **参与人数**: [人数，如 15-30人]
- **学科领域**: [学科，如 物理/光学]
- **核心概念**: [一句话概括]
```

**默认值**:
- 适用年龄: 8-12岁
- 活动时长: 60分钟
- 参与人数: 15-30人

### 3. 活动摘要（推荐）
**要素**:
- 一句话描述活动内容
- 学习收获预览
- 所需材料简要清单
- 安全提醒 highlights

**格式**:
```markdown
## 活动摘要
[活动描述]

**所需材料**: [主要材料]
**安全提醒**: [关键安全提示]
```

### 4. 学习目标
**约束**:
- 数量: 3-5个
- 格式: "参与者能够..."
- 覆盖维度: 知识/技能/态度
- 使用布鲁姆分类法动词（描述/解释/设计/分析等）

**格式**:
```markdown
## 学习目标
完成本活动后，参与者能够：
1. [知识目标] 描述/解释/识别...
2. [技能目标] 操作/制作/使用...
3. [态度目标] 表现出/认识到...
```

### 5. 背景知识（推荐）
**内容**:
- 科学原理（简明版）
- 现实应用（生活中的例子）
- 常见疑问（Q&A形式）

**格式**:
```markdown
## 背景知识
### 科学原理
[简明解释，适合目标年龄段]

### 现实应用
- [应用例子1]
- [应用例子2]
```

### 6. 活动流程（必须包含四阶段）

**标准时间分配**:
| 阶段 | 时长占比 | 典型时长(60分钟活动) |
|-----|---------|---------------------|
| 引入 (Hook) | 15-18% | 10-12分钟 |
| 探索 (Exploration) | 40-50% | 25-30分钟 |
| 讨论 (Discussion) | 20-27% | 12-15分钟 |
| 应用 (Application) | 11-17% | 8-10分钟 |

**各阶段必须包含**:
- **目标**: 该阶段要达成什么
- **内容**: 具体活动步骤（编号列表）
- **话术建议**: 引导员可以说的关键语句（引用格式）

**格式**:
```markdown
## 活动流程

### 阶段一：引入 (X分钟)
**目标**: [目标描述]

**内容**:
1. [步骤1]
2. [步骤2]

**话术建议**:
> "[引导语示例]"

**预期反应**: [可能的问题及应对]

### 阶段二：探索 (X分钟)
**目标**: 

**内容**:
[详细步骤，如果是实验需包含：]
1. 材料分发说明
2. 操作步骤
3. 观察要点
4. 记录要求

**安全提示**: [该阶段特有风险]

### 阶段三：讨论 (X分钟)
**目标**: 

**引导问题**:
1. "[开放性问题]"
2. "[引导发现的问题]"

**概念讲解**: [如何用简单语言解释]

### 阶段四：应用 (X分钟)
**目标**: 

**拓展活动**:
- [延伸思考]
- [生活连接]
- [进阶挑战]
```

### 7. 材料清单
**格式**: 表格

```markdown
## 材料清单
| 材料名称 | 数量 | 规格/要求 | 获取渠道 | 预估成本 |
|---------|------|----------|---------|---------|
| [材料1] | [数量] | [规格] | [渠道] | [成本] |
| [材料2] | [数量] | [规格] | [渠道] | [成本] |
```

**标注**:
- [自备] 需要提前准备
- [现场] 活动场地提供
- [替代] 可用其他材料替代

### 8. 场地要求（推荐）
**内容**:
- 空间大小
- 桌椅布置
- 特殊设施（电源、水源、投影等）
- 环境条件（通风、光线等）

### 9. 安全提示
**必须包含**:
- 风险识别（化学/物理/生物/环境风险）
- 预防措施
- 应急处理

**高风险活动标识**:
| 风险类别 | 必须措施 |
|---------|---------|
| 化学风险 | 防护装备+急救措施 |
| 物理风险 | 安全距离+操作规范 |
| 生物风险 | 消毒+废弃物处理 |
| 户外风险 | 应急预案+监护要求 |

### 10. 评估方式
**内容**:
- 形成性评估（活动中的观察点）
- 总结性评估（活动结束后的检测）
- 检查清单格式

```markdown
## 评估要点
- [ ] [评估点1]
- [ ] [评估点2]
- [ ] [评估点3]
```

### 11. 应急预案（推荐）
**常见情况**:
- 材料不足
- 实验失败
- 时间超出
- 参与者不感兴趣
- 安全问题

**格式**:
```markdown
## 应急预案
- **如果[情况]**: [应对方案]
- **如果[情况]**: [应对方案]
```

### 12. 参考资料（可选）
- 延伸阅读（书籍、文章、视频）
- 标准对齐（课标/NGSS等）
- 相关资源链接

## 格式规范

### Markdown 标准
- 一级标题: `#` （方案名称）
- 二级标题: `##` （主要章节）
- 三级标题: `###` （子章节，如四阶段）
- 四级标题: `####` （可选细分）
- 无序列表: `-` 
- 有序列表: `1. 2. 3.`
- 强调: `**粗体**` 用于关键信息
- 引用: `>` 用于话术示例
- 表格: 材料清单、对比等

### 内容风格
- **正式程度**: 半正式（指导性强但不刻板）
- **人称**: 第二人称（引导员视角，"你可以..."）
- **句式**: 祈使句为主，适当使用问句引发思考
- **术语**: 必要时提供解释，避免过度使用专业术语
