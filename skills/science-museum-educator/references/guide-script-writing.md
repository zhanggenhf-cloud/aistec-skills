# 辅导词写作 — 能力模块指南

## 能力定义

撰写科技馆展品讲解词的能力，包括单件展品辅导词和主题串联辅导词。核心是将科学知识转化为有吸引力、有节奏、有互动点的口头表达文本。

## 核心技能点

1. **结构掌控**：开头抓人、中间递进、结尾有力
2. **语言适配**：根据受众调整用词、句式、语气
3. **互动嵌入**：在关键节点设计提问、手势、停顿
4. **节奏感**：长短句交错，关键信息重复强调
5. **道具/动作配合**：文字与身体语言、展品操作协同

## 训练模式

### 练习任务类型

**类型A：单件展品辅导词**
- 给定展品，要求用户写一段3分钟讲解词（约600-800字）
- 必须包含：现象引入 → 原理揭示 → 互动提问 → 生活关联 → 结尾升华

**类型B：主题串联辅导词**
- 给定3-5件相关展品，要求写一段主题串联讲解
- 必须找到展品间的逻辑主线（因果链/对比链/进化链/问题链）

**类型C：辅导词改写**
- 提供一段学术化/枯燥的讲解文字，要求改写为口语化、有节奏感的辅导词

### 反馈框架

| 维度 | 评价要点 |
|------|---------|
| 开头吸引力 | 前10秒能否抓住观众注意力 |
| 逻辑递进 | 信息是否层层推进，无跳跃 |
| 语言口语化 | 是否适合口头表达，无生僻长句 |
| 互动设计 | 提问/手势/操作点是否自然嵌入 |
| 结尾力度 | 是否留下印象或思考题 |
| 时长控制 | 是否符合目标时长 |

## 生成模式

使用模板 [exhibit-guide-template.md](../assets/exhibit-guide-template.md)，按以下结构生成：

```
# [展品/主题] 辅导词

## 基础信息
- 目标时长：X分钟
- 目标受众：年龄/背景
- 核心知识点：1-2个

## 辅导词正文
[开头：现象/问题/故事引入，10-15秒]
...
[中间：原理揭示，层层递进，配合操作]
...
[互动点1：提问/让观众操作/猜结果]
...
[关联：联系生活或前沿]
...
[结尾：升华或留思考题，10-15秒]

## 动作/道具标注
- [动作1]：...
- [操作展品]：...
- [手势]：...

## 备用互动
- 若观众无反应：...（备用方案）
- 若观众提问深入：...（拓展方向）
- 若时间不够：...（压缩版）
```

## 评估标准

| 维度 | 优秀(5) | 良好(4) | 合格(3) | 待改进(2) | 不足(1) |
|------|--------|--------|--------|----------|--------|
| 开头吸引力 | 现象级引入，观众立刻被抓住 | 有趣但略普通 | 平铺直叙 | 枯燥或突兀 | 不知所云 |
| 逻辑递进 | 层层剥茧，完美过渡 | 整体清晰，偶有跳跃 | 基本连贯 | 逻辑混乱 | 完全断裂 |
| 语言口语化 | 像说话不像念书 | 基本口语化 | 偶有书面语 | 书面化严重 | 学术报告风格 |
| 互动设计 | 互动自然，恰到好处 | 有互动但位置一般 | 互动生硬 | 无互动或强迫互动 | 单向灌输 |
| 结尾力度 | 余韵悠长，引发思考 | 有力但略普通 | 有结尾但不深刻 | 草草收场 | 突然结束 |
| 时长控制 | 精确匹配 | 误差<20% | 误差<30% | 误差>50% | 完全失控 |

## 写作技巧锦囊

1. **开头三板斧**：反常现象 → 震撼数字 → 个人故事（选其一）
2. **过渡句库**：
   - "但你有没有想过…"
   - "如果放大100万倍，你会看到…"
   - "这看似简单的现象，背后藏着…"
   - "科学家花了X年才搞明白…"
3. **互动句库**：
   - "大家猜一猜，接下来会发生什么？"
   - "谁能告诉我，日常生活中哪里见过这个？"
   - "请大家伸手感受一下…"
   - "如果换成XX，结果会变吗？"
4. **结尾句库**：
   - "这个原理，正在改变我们的…"
   - "100年前，科学家XX也是站在这里思考同样的问题"
   - "下次你遇到XX，就知道背后的秘密了"
   - "这个问题，至今还没有完美答案，也许答案就在你们中间"
