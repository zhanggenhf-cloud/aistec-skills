## 活动设计完整流程（内化版）

当用户需要生成**完整教育活动方案**时，执行以下内化流程——无需外部调用，全部在本 skill 内完成。

### 阶段1：5-Stage 知识解构

仿照 OpenMAIC 方法，从科学概念/展品到教育活动方案进行完整解构：

#### Stage 1: 核心概念提取

从输入中提取并定义：
- **主题名称**：正式名称 + 常见别名
- **核心科学原理**：涉及学科、关键定律、1-2句话给外行解释
- **前置知识**：学习者需要的基础知识、年龄适配建议
- **学习目标**：知识目标、技能目标、情感目标

#### Stage 2: 知识点拆解

将核心概念拆解为教学模块：
```
知识点层级结构：
├── 核心概念
│   ├── 子概念 A
│   │   ├── 微观机制
│   │   └── 宏观表现
│   ├── 子概念 B
│   └── 关联概念 C
```
每个模块包含：概念名称、一句话解释、2-3个生活例子、常见误解、演示方式。

#### Stage 3: 教学序列设计（Hook→Explore→Explain→Apply）

1. **引入环节 (Hook)**：引发好奇心的开场（问题/现象/故事），连接日常生活
2. **探索环节 (Exploration)**：动手实验或观察，引导发现而非直接告知
3. **解释环节 (Explanation)**：在体验后用类比和可视化工具讲解概念
4. **应用环节 (Application)**：延伸思考，连接更广泛的科学背景

#### Stage 4: 活动形式匹配

| 活动形式 | 适用场景 | 示例 |
|---------|---------|------|
| 动手实验 | 可观察的物理/化学现象 | 制作简易电路 |
| 观察记录 | 生物/天文/地理现象 | 植物生长日记 |
| 模型制作 | 抽象概念或微观结构 | DNA 双螺旋模型 |
| 角色扮演 | 过程模拟或历史情境 | 扮演水循环中的水滴 |
| 游戏竞赛 | 规则性知识或反应训练 | 元素周期表接龙 |
| 讨论辩论 | 争议性话题或伦理问题 | 基因编辑利弊讨论 |
| 参观考察 | 大型展品或实地场景 | 博物馆/自然保护区 |

#### Stage 5: 难度分层

- **基础版 (Basic)**：观察现象，了解概念
- **进阶版 (Advanced)**：理解原理，解释原因
- **挑战版 (Challenge)**：设计实验，解决新问题

### 阶段2：标准输出格式

基于解构结果，生成标准活动方案骨架：

#### 1. 方案元数据
```yaml
方案名称: [简洁有力的标题]
适用年龄: [年龄段]
活动时长: [总时长，如 60-90分钟]
参与人数: [建议人数，如 10-30人]
学科领域: [物理/化学/生物/天文/地理/综合]
核心概念: [一句话概括]
```

#### 2. 活动摘要 (Executive Summary)
- 一句话描述
- 学习收获
- 所需材料（主要）
- 安全注意事项

#### 3. 学习目标（SMART + 布鲁姆分类）
- 参与者能够描述...（记忆/理解）
- 参与者能够演示...（应用）
- 参与者能够解释...（分析）
- 参与者能够设计...（创造）

#### 4. 背景知识
- 科学原理（简明版）
- 现实应用
- 常见疑问及简要答案

#### 5. 活动流程（四阶段）
- **阶段一：引入 (Hook)** [时长] — 目标、内容、话术建议、预期反应
- **阶段二：探索/实验 (Exploration)** [时长] — 步骤、观察要点、安全提示
- **阶段三：讨论/解释 (Discussion)** [时长] — 引导问题、概念讲解、类比使用
- **阶段四：应用/拓展 (Application)** [时长] — 延伸活动、生活连接、进阶挑战

#### 6. 材料清单
| 材料名称 | 数量 | 规格/要求 | 获取渠道 | 预估成本 |
标注：自备/现场/替代

#### 7. 场地要求
空间大小、桌椅布置、特殊设施、环境条件

#### 8. 人员配置
主讲、助教、志愿者、专家支持

#### 9. 评估方式
形成性评估（活动中观察）、总结性评估（结束后检测）、参与度指标、学习效果指标

#### 10. 应急预案
材料不足、实验失败、时间超出、参与者不感兴趣、安全问题

#### 11. 参考资料
延伸阅读、标准对齐、相关资源

#### 12. 附件
工作纸/记录表模板、PPT/海报设计建议、背景阅读材料（给引导员）

### 阶段3：科技馆适配

将标准方案转化为科技馆场景专用：

- **展厅寻宝/探索环节**：利用真实展品作为锚点，设计展厅内的探索任务
- **家庭亲子协作**：设计需要家长和孩子共同完成的环节
- **辅导员-观众互动模式**：嵌入辅导员讲解、提问、引导的节点
- **展厅场地与展品锚点**：明确使用哪些展品、在哪个展区进行
- **安全评估**：基于展厅环境的安全预案（人流、展品操作、应急通道）
- **备选方案**：时间不足、人数超预期、设备故障、天气（户外活动）

### 阶段4：多层纠错与准确性保障

#### 纠错层级（Layer 1→2→3）

**Layer 1: 输入预处理**
- 输入分类：科学概念 / 展品介绍 / 活动需求 / 混合输入
- 需求澄清：必须确认年龄、时长、人数、资源约束（若未明确则提问）
- 输出标准化内部表示

**Layer 2: 生成中监控**
- 结构约束：知识点是否完整树状、是否有孤立点、类比是否恰当
- 流程约束：四阶段是否完整、时间分配是否合理、过渡是否自然
- 可操作约束：材料是否易获取、步骤是否清晰、时间估算是否现实
- 安全约束：是否识别所有风险、是否有防护措施、是否有应急预案
- 实时纠正触发器：
  - 概念错误 → 重新检索
  - 超龄内容 → 降维解释
  - 不可行操作 → 寻找替代方案
  - 逻辑跳跃 → 补充过渡
  - 时间失衡 → 重新分配

**Layer 3: 输出后验证**
- 完整性检查：12个章节是否齐全
- 科学性验证：理论表述正确、公式准确、因果关系成立
- 安全性检查：高风险活动标识、防护措施、应急流程
- 教育有效性检查：布鲁姆分类覆盖、参与式设计、不同水平成就感

#### 准确性标注规范

在方案中使用以下标注：
- 🔬 科学事实（已验证）
- 📐 简化模型（为教学目的简化）
- 🎭 教学类比（帮助理解的比喻）
- ⚠️ 常见误解（学习者容易产生的错误）
- ❓ 前沿问题（科学界正在研究中）

#### 知识来源分级
- **Tier 1**（直接引用）：同行评审期刊、权威教材、科研机构官网、国际科学教育标准
- **Tier 2**（参考使用）：知名科普作者/机构、权威博物馆/科技馆教育资料
- **Tier 3**（需交叉验证）：一般网络资源、AI生成内容（需人工核实）

#### 认知发展匹配（皮亚杰）
| 阶段 | 年龄 | 特点 | 适配策略 |
|-----|------|------|---------|
| 前运算 | 2-7岁 | 直觉思维 | 具体实物操作，故事化 |
| 具体运算 | 7-11岁 | 逻辑思维需支持 | 动手实验，具体例子 |
| 形式运算 | 11岁+ | 抽象思维 | 概念讨论，设计实验 |

#### 自动纠错触发条件
```yaml
triggers:
  - 缺少必要章节 → 补全缺失部分
  - 科学概念明显错误 → 重新解构知识
  - 安全提示缺失 → 添加安全评估章节
  - 活动时长与阶段不匹配 → 重新分配时间
  - 材料清单不完整 → 补充材料和规格
  - 学习目标与活动不对应 → 调整目标或活动设计
```

#### 人工审核标记
> ⚠️ **需要确认**：本活动涉及[具体内容]，请确认：
> 1. 目标年龄段是否适合？
> 2. 场地和设备条件是否满足？
> 3. 是否需要专业人员陪同？

## 训练模式

### 练习任务类型

**类型A：完整活动方案设计**
- 给定主题/受众/时长，要求输出完整方案
- 使用模板 [activity-plan-template.md](../assets/activity-plan-template.md)

**类型B：活动片段设计**
- 给定一个环节（如"导入""探究""总结"），要求设计该环节的具体活动
- 聚焦：如何用3分钟抓住注意力？如何设计10分钟探究？如何用5分钟总结升华？

**类型C：方案评估与优化**
- 提供一份活动方案，要求评估其教育性和可行性
- 给出具体改进建议（时间、材料、互动、安全等）

### 反馈框架

| 维度 | 评价要点 |
|------|---------|
| 目标清晰度 | 学习目标是否明确、可测量 |
| 逻辑连贯性 | 环节之间是否有内在逻辑 |
| 互动丰富度 | 是否有动手、讨论、探索、创造 |
| 时间合理性 | 每环节时长是否匹配内容 |
| 材料可行性 | 材料是否易得、安全、低成本 |
| 评估完整性 | 是否有前置/过程/后置评估 |
| 安全考量 | 是否有风险识别和预案 |

## 设计原则

1. **5E模型**（科技馆适配版）：
   - **Engage（参与）**：用反常现象、震撼演示或问题引入
   - **Explore（探究）**：观众动手、观察、记录，辅导员不急着给答案
   - **Explain（解释）**：在观众有了体验后，引导归纳原理
   - **Elaborate（拓展）**：联系生活、前沿、历史，或提出更难的问题
   - **Evaluate（评估）**：用观察、提问、作品而非纸笔测试

2. **游戏化设计**：
   - 积分/徽章：完成任务获得"科学家勋章"
   - 角色扮演："你是地质勘探队，任务是…"
   - 竞争合作：小组PK + 全班共享成果
   - 进度条："完成3个挑战，解锁终极秘密"

3. **差异化设计**：
   - 同一活动提供"基础版"和"挑战版"
   - 为低龄儿童提供图片辅助，为高龄提供数据表格
   - 为特殊需求观众提供替代参与方式

4. **科技馆特有优势**：
   - 利用真实展品作为锚点，而非虚拟模拟
   - 利用展厅环境作为探索空间，不限于教室
   - 利用观众自愿参与的心态，设计深度体验
   - 利用家庭组合（家长+孩子），设计亲子协作环节
