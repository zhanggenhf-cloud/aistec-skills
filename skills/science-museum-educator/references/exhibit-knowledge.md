# 展品原理知识 — 能力模块指南

## 能力定义

科技馆辅导员对展品背后科学原理的理解深度、知识网络构建能力、以及将复杂原理转化为观众可理解语言的能力。

## 核心技能点

1. **原理拆解**：能分解展品的物理/化学/生物/数学原理到基础定律层级
2. **知识关联**：能将展品与日常生活、前沿科技、历史发现建立关联
3. **受众分层**：能为不同年龄/背景观众调整原理讲解深度
4. **纠错能力**：能识别观众常见误解并科学纠正

## 训练模式

### 练习任务类型

**类型A：原理拆解练习**
- 给出一件展品，要求用户写出：
  - 核心科学原理（一句话）
  - 涉及的基础定律/公式（列出）
  - 日常生活中的3个类比案例
  - 观众最常见的1个误解及纠正方式

**类型B：知识关联练习**
- 给定展品，要求用户建立知识网络：
  - 向上关联：该原理在哪个前沿领域有应用？
  - 横向关联：同原理的其他展品有哪些？
  - 向下关联：该原理的日常现象有哪些？

**类型C：深度讲解练习**
- 模拟面对特定受众（如8岁儿童/高中生/退休工程师）进行60秒讲解
- 要求：开头用现象或问题引入，中间讲核心原理，结尾留一个思考题

### 反馈框架

对每次练习按以下维度评分（1-5星）：
- 原理准确性：科学内容是否准确
- 深度适配：是否匹配目标受众认知水平
- 关联丰富度：知识网络是否足够宽广
- 表达清晰度：语言是否简洁易懂
- 互动设计：是否预留了提问或动手空间

## 生成模式（内化版）

当用户需要获取某展品的知识包时，执行以下内化流程——无需外部调用，全部在本 skill 内完成。

### 阶段1：展品原理与脉络梳理（内置研究验证）

#### 搜索策略

用英文和中文分别构造搜索词，执行多轮搜索：

```
第1轮：主题 overview
  - "[主题] review survey history"
  - "[主题] 研究进展 综述"

第2轮：关键里程碑
  - "[主题] landmark paper breakthrough"
  - "[主题] 里程碑 关键发现"

第3轮：时间线填充
  - "[主题] timeline evolution history"
  - 搜索具体年份 + 主题，验证关键事件

第4轮（可选）：前沿与分支
  - "[主题] recent advances 2024 2025"
  - "[主题] subtopics research directions"
```

#### 研究验证机制（内置精确性验证）

**验证铁律**：每个关键文献、年份、作者、机构都必须达到 `VERIFIED`（已验证）或 `NOT_FOUND`（未找到）状态。"难以验证"不可接受。

**五类幻觉检测清单**（对每条文献强制扫描）：

| 类型 | 代码 | 说明 | 检测策略 |
|------|------|------|----------|
| **完全伪造** | TF | 整篇论文或关键事件不存在 | WebSearch 标题+作者，无结果 = TF |
| **真实作者伪作** | PAC | 真实学者被安上不存在的论文 | 通过 Google Scholar / Semantic Scholar 核对该作者发表列表 |
| **信息不全** | IH | 缺少 DOI、卷号、页码或具体年份 | 标记为 `[待验证]`，需额外搜索补全 |
| **拼接伪造** | PH | 从 2-3 篇真实文献拼接出假引用 | 交叉核对：标题、作者、期刊、年份必须全部匹配同一来源 |
| **微妙扭曲** | SH | 年份、作者缩写、期刊轻微错误 | 逐字段对比出版页面或数据库记录 |

**文献验证流程（A→B→C→D）**：

**步骤 A：Semantic Scholar API 快速筛查**
- 批量查询作者+标题组合，同时获取 `abstract` 字段
- 若返回 `S2_VERIFIED` → 进入步骤 B
- 若 `S2_NOT_FOUND` → 进入步骤 C
- 若 `API_UNAVAILABLE` → 直接进入步骤 C

**步骤 B：书目细节交叉核对**
- 确认作者、标题、年份、期刊/会议名全部一致
- 检查 DOI 是否存在且可解析
- 检查页码/卷号是否与出版记录匹配
- 核对摘要是否与出版商页面一致

**步骤 C：WebSearch 逐条验证（当 API 不可用时）**
- 用不同关键词组合搜索至少 3 次：
  - `[作者名] [标题关键词] [年份]`
  - `[标题] DOI`
  - `[作者] [期刊名] [年份]`
- 3 次均无明确结果 → 标记为 `NOT_FOUND`
- 任何一次返回明确结果 → 记录来源 URL，标记为 `VERIFIED`
- 同时尝试从搜索结果或出版商页面获取摘要

**步骤 D：时间线一致性验证**
- 检查论文发表年份是否早于后续引用它的论文
- 检查"奠基期"论文是否早于"突破期"论文
- 检查技术出现时间是否早于声称的应用落地时间
- 若发现时间悖论 → 标记为 `[时间线待核实]`

#### 获取摘要的途径（按优先级）

1. **Semantic Scholar API** — 通过 `paperId` 或 `DOI` 查询 `abstract` 字段（最可靠）
2. **arXiv API** — 对 arXiv 论文，通过 `http://export.arxiv.org/api/query?id_list=XXXX.XXXXX` 获取摘要
3. **Crossref API** — 通过 DOI 查询 `abstract` 字段（部分出版商提供）
4. **WebSearch 直接获取** — 搜索 `"[论文标题]" abstract` 或访问出版商页面抓取摘要
5. **Google Scholar 页面** — 作为最后手段，从搜索结果摘要中摘录

**摘要获取失败的处理**：
- 若无法获取摘要 → 标注 `[摘要未获取]`，但文献仍保留（只要验证通过）
- 若摘要获取成功但为非英文（如中文论文）→ 直接输出原文，无需翻译原文部分

#### 文献翻译要求

对每篇通过验证的关键文献，必须提供以下中文翻译：
- **题目中文翻译**：准确、学术化，保持原标题的学术语气
- **摘要中文翻译**：完整翻译，不遗漏技术细节、数据、结论

**翻译规范**：
- 人名、机构名、专有术语保留原文或在首次出现时括号注明原文
- 数学公式、化学式、算法名称保留原文
- 不添加原文没有的解读或评论——翻译只传递信息，不创造价值判断
- 若原文存在多义词或翻译歧义，选择最符合该学科惯例的译法

#### 溯源标注规范

所有经过验证的信息，必须在输出中标注可信度：

| 标注 | 含义 | 使用条件 |
|------|------|----------|
| 无标注 | 已验证，来源可靠 | 通过 WebSearch/API 确认，来源权威 |
| `[待验证]` | 信息来源有限，无法确认 | 搜索未返回明确结果 |
| `[信息来源有限]` | 搜索结果稀少，可能遗漏 | 小众主题，权威综述尚未覆盖 |
| `[争议]` | 多个来源存在矛盾 | 年份、优先权、作者归属存在学术争议 |
| `[推测]` | 基于现有信息的合理推断 | 明确说明为推断，非已验证事实 |
| `[摘要未获取]` | 无法获取摘要原文 | 验证通过但摘要不可得 |

#### 反同源幻觉策略

- **必须 WebSearch**：不能因"这篇论文很有名"就跳过搜索
- **交叉验证**：同一关键事件通过至少 2 个独立来源确认
- **怀疑默认**：对任何未经搜索的引用保持怀疑，直到验证通过
- **特别警惕**：经典/里程碑论文最容易被伪造——因为"所有人都知道有这篇论文"，所以幻觉更容易通过直觉检查

#### 研究脉络梳理

从验证过的信息中提炼出研究脉络：

**时间维度**：
- 起源期（谁首次提出？什么问题启发了这个方向？）
- 奠基期（关键理论/实验建立，哪些论文必读？）
- 爆发期（技术突破、应用落地，什么让研究激增？）
- 分化期（出现不同分支方向，主要学派有哪些？）
- 当前期（最新进展、开放问题、争议点）

**关键节点识别**：
- 里程碑论文（作者、年份、核心贡献、一句话总结）
- 技术转折点（什么发现让方向改变？）
- 争议与修正（哪些假设被推翻？哪些学派在争论？）

### 阶段2：展品知识包生成

将验证后的研究脉络融入展品知识包：
- 首次发现年份/科学家（标注 [VERIFIED]）
- 关键里程碑（标注验证状态）
- 当前前沿（标注 [待验证] 或 [VERIFIED]）
- 关键文献索引（附摘要和翻译）
- 历史故事素材（科学家的困惑、关键实验瞬间、意外发现）

## 评估标准

评估用户提交的展品知识内容：

| 维度 | 优秀(5) | 良好(4) | 合格(3) | 待改进(2) | 不足(1) |
|------|--------|--------|--------|----------|--------|
| 原理准确性 | 完全准确，无遗漏 | 准确，偶有小瑕疵 | 大体准确 | 有错误但不严重 | 有明显错误 |
| 深度适配 | 完美匹配受众 | 偶有偏深/偏浅 | 基本匹配 | 明显不匹配 | 完全不匹配 |
| 关联丰富度 | 跨学科+前沿+日常 | 2类关联 | 1类关联 | 关联牵强 | 无关联 |
| 表达清晰度 | 外行秒懂 | 稍加解释即可懂 | 需要一些背景 | 较为晦涩 | 难以理解 |
| 互动设计 | 自然的提问/动手点 | 有互动意识 | 互动生硬 | 无互动 | 单向灌输 |

## 示例：电磁弹射展品

**核心原理**：电磁感应 + 洛伦兹力。变化的磁场在导体中感应出电流，电流在磁场中受到力的作用，推动导体运动。

**基础定律**：
- 法拉第电磁感应定律：$\mathcal{E} = -\frac{d\Phi_B}{dt}$
- 洛伦兹力：$\vec{F} = q(\vec{E} + \vec{v} \times \vec{B})$

**日常类比**：
1. 电磁炉：变化磁场 → 锅底感应电流 → 发热
2. 磁悬浮列车：电磁力推动列车前进
3. 手机无线充电：电磁感应传递能量

**常见误解**：
- 误解："电磁弹射跟弹弓一样是靠弹力" → 纠正："电磁弹射没有弹簧，是靠磁场力量推动的，就像两个磁铁靠近会推开或吸引一样"

**前沿关联**：航母电磁弹射系统（福特级）、磁悬浮发射技术、电磁炮
