# Science Education Activity Skill

一个用于生成全面、教学法严谨的科学教育活动方案的 OpenClaw AgentSkill。将科学概念或展品描述解构为适合博物馆、学校和科学中心的可教学活动。

## 这个技能做什么

通过以下方式将科学概念转化为引人入胜的教育体验：

- **问题逻辑转换** — 将"论文逻辑"转换为"问题逻辑"：找准*挂钩点*（这个概念解决了什么日常烦恼？）并设计*天钩类比*（将陌生概念锚定到熟悉经验）
- **科学叙事素材收集** — 收集让科学人性化的故事片段：失败的时刻、意外发现，以及让科学变得可亲的"洗澡时的灵光一闪"
- **教学框架自动选择** — 基于主题和约束条件从 12+ 个框架（5E、4阶段、PBL、设计思维、IBL、引导式游戏、POE 等）中自动选择
- **UDL × SDT 整合设计** — 通用学习设计与自我决定理论融合，在支持多元学习者的同时培养内在动机
- **ICAP 认知参与评估** — 确保活动进程从被动 → 主动 → 建构 → 互动逐步攀升
- **Chain-of-Evidence (CoE) 零误引架构** — 通过多 API 交叉验证（Semantic Scholar、arXiv、CrossRef、Google Scholar、知网）确保引用零幻觉
- **双格式输出** — 每个方案同步生成标准 Markdown 文本教案 + 页面级可执行活动方案（SL/IA/QZ/PB 四种页面类型，含学习契约、ICAP 档位、NGSS 对齐和 TTS 就绪旁白）
- **知识图谱集成** — 通过 AISTEC 知识图谱自动查询，实现前置知识诊断、学段适配检查和常见误解预加载

## 支持领域

物理 · 化学 · 生物 · 天文 · 地理 · 跨学科 STEM/STEAM

## 输出包含

- 活动元数据（年龄、时长、人数、学科）
- 理论框架选择及理由
- SMART 学习目标（Bloom 对齐）
- 带验证文献引用的背景知识
- 框架专属活动流程及主持指南
- UDL 差异化设计方案
- STEM/STEAM 整合映射
- 元认知嵌入节点
- ICAP 认知参与层次标注
- 材料清单及成本估算
- 安全协议及应急预案
- 馆校合作指南（适用时）
- 家庭学习指南（适用时）
- 含 UDL 替代方案的评估量规
- 页面级可执行方案（每页标注 ICAP/NGSS/元认知/SDT）

## 核心设计理念

| 理念 | 实现方式 |
|-----------|---------------|
| **先找挂钩** | 每个活动回答三个问题：*像什么？有什么用？跟我有什么关系？* |
| **坦诚局限** | 主动披露当前不确定性（⚠️ 已知局限）— 用透明建立信任 |
| **设计挣扎** | 预留有效失败空间，不急于给出答案 |
| **多受众就绪** | 准备一句话版（外行）、一段话版（爱好者）和详细版（同行） |
| **叙事丰富** | 融入科学挣扎故事、意外发现案例和当代研究者声音 |
| **参与接口** | 开放性问题和动手挑战将学习变成智力游戏 |

## 何时使用

- 为科技馆、自然中心或创客空间设计教育活动方案
- 为学校科学课设计教案
- 将展品描述转化为互动教育体验
- 为各年龄段开发 STEM/STEAM 活动
- 将复杂科学概念适配为公众可理解的形式

## 使用方法

```
# 概念到活动
"设计一个关于光的折射的科普活动，适合小学生"

# 展品到活动
"我们有一个范德格拉夫起电机展品——设计一个配套活动"

# 需求驱动
"45 分钟，20 个孩子，8-10 岁，预算低于 50 元，物理"
```
