# ICAP 认知参与框架

> 来源：Chi & Wylie (2014), ICAP: A Theory of Active Learning
> 核心观点：学习效果取决于认知参与层次，而非表面上的"活跃程度"

## ICAP 四档定义

| 档位 | 名称 | 学生外显行为 | 学习效果 | 升档策略 |
|------|------|-------------|---------|---------|
| **P** | 被动 (Passive) | 接收信息，不做其他事 | 基准线 | → 加"用自己的话总结" |
| **A** | 主动 (Active) | 重复/复制/操练 | P的1.5倍 | → 加"解释为什么" |
| **C** | 建构 (Constructive) | 产生新内容（超出给出的） | P的2倍 | → 加"同伴互评" |
| **I** | 互动 (Interactive) | 对话+轮流建构 | P的3倍 | 最高档 |

> **关键洞察**："动手做"不等于"动脑学"。一个学生在动手实验但只按步骤执行（A档），学习效果可能不如另一个学生在听讲解但一直在用自己的话做笔记（C档）。

## 常见活动升档对照表

| 活动 | P挡 | A挡 | C挡 | I挡 |
|------|-----|-----|-----|-----|
| **听讲** | 只听 | 边听边划重点 | 听完用自己的话写总结 | 两人互讲互评总结 |
| **阅读** | 通读 | 划线+标注 | 画概念图 | 讨论后合作画概念图 |
| **做题** | 看示范题 | 照步骤做一遍 | 做完加"解释我的思路" | 互批+互相讲解 |
| **讨论** | 听别人讨论 | 记录别人的观点 | 提出自己的观点+理由 | 回应+反驳+补充别人 |
| **笔记** | 无 | 逐字抄板书 | 用自己的话重组 | 和同桌交换笔记互相补充 |
| **实验** | 看老师做 | 按步骤操作 | 预测+记录+解释异常 | 小组设计改进方案 |
| **观察** | 随意看 | 按清单逐项观察 | 提出自己的观察问题 | 分享发现，互相质疑 |

## 升档策略工具箱

### P → A（被动 → 主动）

**核心动作**：从"接收"到"做点什么"

| 策略 | 适用场景 | 具体操作 |
|------|---------|---------|
| 划重点/标记 | 听讲、阅读 | 边听边用符号标记关键信息 |
| 填空/完形 | 讲解后巩固 | 提供部分信息，学生补充 |
| 跟读/复述 | 概念讲解 | 教师讲完后学生用自己的话复述 |
| 操作步骤执行 | 实验/制作 | 按给定步骤完成操作 |

### A → C（主动 → 建构）

**核心动作**：从"照着做"到"产出新东西"

| 策略 | 适用场景 | 具体操作 |
|------|---------|---------|
| 出声思考 (Think Aloud) | 解题/阅读 | 说出发声"我在想什么" |
| 概念图/思维导图 | 知识整理 | 用自己的话重组知识结构 |
| 预测-观察-解释 (POE) | 实验 | 实验前先预测，再解释差异 |
| 自我提问清单 | 任何环节 | 自己设计问题并回答 |
| "为什么"追问链 | 任何讲解 | 对每个结论追问"为什么" |

### C → I（建构 → 互动）

**核心动作**：从"自己想"到"和别人一起想"

| 策略 | 适用场景 | 具体操作 |
|------|---------|---------|
| 发言筹码 | 小组讨论 | 每人X个筹码，用完闭口 |
| 拼图阅读 (Jigsaw) | 阅读/资料分析 | 每人只读一部分，互相教 |
| 同伴互评 | 作品/报告 | "一个优点+一个改进" |
| 辩论/正反方 | 争议话题 | 轮流陈述+反驳+回应 |
| 旋转木马 (Gallery Walk) | 展示/讨论 | 各组循环留言评论 |
| 六顶思考帽 | 方案讨论 | 轮流从六种角度评价 |

## ICAP 在活动设计中的应用

### 1. 整体趋势检查

一个好的活动方案，ICAP 层次应该呈现**上升趋势**，而不是平铺或下降：

```
❌ 不好的趋势：P → P → A → P（波动，没有持续上升）
✅ 好的趋势：   P → A → C → I（逐步升档）
✅ 好的趋势：   A → C → I → I（先升后稳在高档）
```

### 2. 每阶段标注格式

在活动方案中，每个阶段标注目标 ICAP 档位和升档策略：

```markdown
#### 阶段X：[阶段名称] (X分钟)
**ICAP 目标档位：A → C**
**升档策略**：从"按步骤操作"升级为"预测+解释异常"

[活动描述...]
```

### 3. 关键升档节点

以下节点是自然的升档机会，不要错过：

| 节点 | 自然升档 | 策略 |
|------|---------|------|
| 引入/导入 | P → A | 从"听故事"到"提问题" |
| 实验操作 | A → C | 从"按步骤做"到"预测+解释" |
| 数据记录 | A → C | 从"填表格"到"发现规律+解释" |
| 讨论分享 | C → I | 从"展示结果"到"互相质疑+补充" |
| 总结反思 | C → I | 从"写总结"到"同伴互评总结" |

## ICAP 与教学框架的对应

| 教学框架 | 典型 ICAP 分布 | 说明 |
|---------|---------------|------|
| **5E** | E(P)→E(A)→E(C)→E(C)→E(I) | Engage多为P/A，Evaluate可达I |
| **4-Stage** | H(P)→E(A)→D(C)→A(C/I) | Hook常为P，Apply可达I |
| **PBL** | P(P)→I(A/C)→D(C)→P(C/I)→R(I) | 项目展示和反思可达I |
| **Design Thinking** | E(P)→D(C)→I(C)→P(A/C)→T(I) | 测试阶段互相反馈达I |
| **Guided Play** | F(P/A)→G(A/C)→S(C)→F(I) | 家庭分享促进互动建构 |

## ICAP 设计自检清单

- [ ] 每个活动阶段是否标注了目标 ICAP 档位？
- [ ] 整体 ICAP 趋势是否呈上升或稳定在高挡？
- [ ] 是否存在连续多个 P 档阶段？（如有，考虑升档）
- [ ] 最高档 I 是否出现在需要深度建构的环节？
- [ ] 升档策略是否具体可操作（学生拿到就知道怎么做）？
- [ ] 是否避免了"假互动"（物理在一起，心理独立）？

## 常见误区

| 误区 | 实际情况 | 修正 |
|------|---------|------|
| "动手做就是主动学习" | 按步骤操作只是 A 档 | 加入"预测+解释"升到 C |
| "小组讨论就是互动" | 各说各的是 C，不是 I | 加入"回应+反驳"机制到 I |
| "游戏化就是高参与" | 游戏本身可能是 P 或 A | 游戏机制设计要促进建构 |
| "热闹=学习效果好" | 表面的活跃不等于认知参与 | 用 ICAP 评估真实认知层次 |
