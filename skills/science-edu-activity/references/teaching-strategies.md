# 教学策略工具映射表

> 核心原则：教法只规定了"谁来干"（课堂分工），真正让目标落地的是**策略工具**（具体工具）。
> 来源：教学设计知识库 + 哈士奇聊教学设计系列

## 关键警告：教法学法 ≠ 教学策略

```
教法学法：
  → 解决"谁来干"（课堂分工）
  → 例：讲授法、小组合作、探究式学习、任务驱动
  → 问题：只搭了舞台，没写剧本

教学策略：
  → 解决"怎么干"（具体工具）
  → 例：发言筹码、拼图阅读、故事山、问题矩阵
  → 价值：学生拿到就会用的具体工具
```

**教师最常见的错误**：
```
❌ "本节课采用小组合作与探究式教学"
   → 这是套话，放哪节课都能用
   → 只写了姿态，没写动作

✅ "运用发言筹码机制确保全员参与，
   配合问题矩阵引导学生从低阶走向高阶提问"
   → 这才是真正能用的策略
```

## 三条获取策略的路径

**路径1️⃣ 向上抽**
- 看到一个好活动（如"角色扮演模拟星体运行"）
- 别只记教法名"情境模拟法"
- 抽出底层策略："具身认知"
- 教法跨不了学科，策略可以

**路径2️⃣ 跨界偷**
- 最好的策略往往不在教育学课本里：
  - "故事山" → 偷自好莱坞三幕剧
  - "鱼骨图" → 偷自企业质量管理
  - "六顶思考帽" → 偷自商业咨询
  - "SWOT分析" → 偷自战略管理

**路径3️⃣ 命名封装**
- 画不出来的策略就只是一团感觉
- 给它起个名字
- 画成图表/模板
- 写清楚什么时候用它
- 让它变成工具箱里随时能拿出来的东西

## 策略工具速查卡

### 合作学习类

| 工具名称 | 一句话说明 | 什么时候用 |
|---------|-----------|-----------|
| 发言筹码 | 每人X个筹码，用完闭口 | 防止少数人垄断发言 |
| 拼图阅读 | 每人只读一部分，互相教 | 资料多、时间紧 |
| 轮流发言棒 | 谁拿棒谁发言，传完一轮 | 需要确保人人发言 |
| 旋转木马 | 各组循环留言评论 | 多组展示时 |
| 内外圈 | 内圈讨论，外圈听，轮换 | 需要大量配对讨论 |

### 思维可视化类

| 工具名称 | 一句话说明 | 什么时候用 |
|---------|-----------|-----------|
| 思维导图 | 中心主题→分支联想 | 知识整理、复习 |
| 鱼骨图 | 中心问题→左右分因果 | 问题归因分析 |
| 双栏笔记 | 原文摘录 | 我的理解 | 阅读、概念辨析 |
| K-W-L表 | 已知-想知-学到 | 活动前中后 |
| 概念关系网 | 节点+连接词 | 概念间关系梳理 |

### 提问技术类

| 工具名称 | 一句话说明 | 什么时候用 |
|---------|-----------|-----------|
| 问题矩阵 | 从"是什么"→"为什么"→"如果...会怎样" | 引导学生深度思考 |
| I-R-E链 | 老师问-学生答-老师评价 | 快速检查理解 |
| 追问链 | 为什么？还有呢？这和XX有什么关系？ | 学生回答后深化 |
| 自我提问清单 | 学生自己设计问题 | 培养元认知 |

### 实验探究类

| 工具名称 | 一句话说明 | 什么时候用 |
|---------|-----------|-----------|
| 预测-观察-解释(POE) | 先预测，再观察，最后解释 | 反直觉现象 |
| 控制变量打勾表 | 自变量/因变量/控制变量清单 | 设计实验时 |
| 探究路线图 | 步骤1/2/3，每步做什么 | 开放探究时 |
| 失败记录表 | 记录失败+分析原因+改进 | 有效失败设计 |

### 评估反馈类

| 工具名称 | 一句话说明 | 什么时候用 |
|---------|-----------|-----------|
| 评分量规对照表 | 满分答案长什么样 | 任务开始前 |
| "优点+改进"反馈 | 发现一个优点+一个改进 | 同伴互评 |
| 红绿灯自评 | 绿=懂，黄=部分懂，红=不懂 | 随时检查理解 |
| 进步可视化墙 | 记录每次的进步 | 长期项目 |

## 策略工具"跨界来源"一览

| 策略工具 | 跨界来源 | 适用教法 |
|---------|---------|---------|
| 故事山 | 好莱坞三幕剧结构 | 故事教学 |
| 鱼骨图 | 企业质量管理（石川馨） | 思维导图/概念图 |
| 六顶思考帽 | 商业咨询（爱德华·德博诺） | 讨论法 |
| 发言筹码 | 课堂管理机制 | 小组合作 |
| 拼图阅读 | 合作学习理论（Aronson） | 小组合作 |
| SWOT分析 | 战略管理 | 探究式教学 |
| K-W-L表 | 阅读策略（Ogle） | 概念图/复习 |
| GRASPS | 理解性教学设计（Wiggins） | PBL |

## 写教案的自检

在写下"合作探究"之前，先问自己：

> 当学生面对这个难点的时候，
> 我递给他的那把具体的工具，到底长什么样？

如果答不上来 → 你的教法学法栏写的是套话
