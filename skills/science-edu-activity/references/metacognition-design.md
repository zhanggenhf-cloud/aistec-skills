# 元认知嵌入教学设计

> 来源：元认知教学研究 + AIED 知识库
> 核心文献：Flavell (1979) 元认知理论、《认知科学与教育》
> 核心原则：元认知不是额外加时间，而是**替换**现有低认知活动

## 什么是元认知

### 定义

> 元认知 = 思考自己的思考
> 知道自己知道什么、不知道什么、怎么知道的、怎么学会的

### 两大成分

```
元认知知识（知道什么策略 + 什么时候用 + 自己适合什么）：
  - 陈述性知识："我知道解释和总结是不同的策略"
  - 程序性知识："我知道怎么用概念图整理知识"
  - 条件性知识："我知道什么时候该用概念图而不是死记硬背"

元认知调节（计划→监控→评估→调整）：
  - 计划：学之前想"我打算用什么方法？"
  - 监控：学之中想"我现在理解了吗？卡在哪？"
  - 评估：学之后想"我学会了吗？什么方法最有效？"
  - 调整：根据评估决定"下次我该怎么做？"
```

## 元认知嵌入的三个关键策略

### 策略1：出声思考（Think Aloud）

**教师示范**：
教师朗读或演示时，说出发声"我在想什么"——
- "哦，这里作者说……但我有个疑问……"
- "我刚才没看懂这段，所以我倒回去重读了一遍……"
- "这个角色说的话，让我联想到……"

**学生练习**：
- 两人一组，一人解题/阅读时说出思考过程
- 另一人听，结束后总结"他用了什么策略？卡在哪？"

**在科学教育活动中的应用**：
- 实验前："我预测会发生什么，因为……"
- 实验中："我观察到……这和我预测的一样/不一样，因为……"
- 实验后："我的结论是……但我不确定的是……"

### 策略2：反思卡（嵌入每个关键节点）

**活动前（2分钟）**：
- "我打算用什么方法？"
- "这个活动和上次做过的有什么相似/不同？"
- "我需要特别注意什么？"

**活动中（随时）**：
- "我现在理解了吗？"
- "卡在哪一步？"
- "我还能用什么其他方法？"

**活动后（3-5分钟）**：
- "这次我用了什么方法？有效吗？"
- "卡在哪？下次怎么避免？"
- "和上一次比，我进步了什么？"

**反思卡模板（供活动方案使用）**：

```markdown
### 反思卡：[活动名称]

**开始前**
□ 我知道今天要做什么
□ 我预测会学到……
□ 我最想知道的是……

**进行中**
□ 我现在理解了吗？（绿灯/黄灯/红灯）
□ 我卡在哪里？
□ 我可以尝试什么不同方法？

**结束后**
□ 我学到了什么？（用一句话）
□ 我最成功的时刻是……
□ 我下次会怎么做 differently？
```

### 策略3：自我提问清单（学科通用版）

**探究前**：
- □ 我理解这个问题吗？（用自己的话复述一遍）
- □ 这和以前做过的探究有什么相似之处？
- □ 我需要什么信息？还需要什么？

**探究中**：
- □ 我现在在用的方法对吗？
- □ 卡住了 → 我可以尝试什么不同方法？
- □ 我的观察/数据是合理的吗？（快速估算验证）

**探究后**：
- □ 我的结论对吗？怎么验证？
- □ 有没有更好的方法？
- □ 这次探究教了我什么？我下次遇到类似的会怎么做？

## 元认知嵌入的活动设计

### 嵌入位置（不额外加时间，而是替换）

```
❌ 错误做法：活动末忽然说"现在花5分钟反思"（流于形式）
✅ 正确做法：替换现有的低认知活动

替换示例：
  原来的"抄板书" → 替换为"用自己的话写总结+说明为什么这么理解"
  原来的"做10道题" → 替换为"做8道题+写2道题的解题思路分析"
  原来的"记住公式" → 替换为"解释这个公式和之前那个公式的关系"
  原来的"填写实验记录表" → 替换为"填写记录表+标注最意外的发现"
```

### 科学教育活动中的嵌入示例

| 活动类型 | 元认知嵌入点 | 具体策略 |
|---------|------------|---------|
| **观察活动** | 观察后 | "你注意到了什么别人可能没注意的？" |
| **实验活动** | 预测前 | "写下你的预测和理由" |
| | 数据记录中 | "这个数据和你预期的一样吗？" |
| | 结论后 | "如果你的结论错了，可能是什么原因？" |
| **模型制作** | 设计前 | "我打算怎么解决这个问题？" |
| | 测试后 | "哪里和我想的不一样？我学到了什么？" |
| **讨论活动** | 发言前 | "我要说的观点，证据是什么？" |
| | 倾听时 | "我同意/不同意，因为……" |
| **角色扮演** | 扮演后 | "扮演这个角色让我理解了什么？" |

## 元认知在活动方案中的标注

在活动方案中，明确标注元认知嵌入点：

```markdown
#### 阶段X：[阶段名称] (X分钟)

**教学活动过程**

*教师活动*：
1. 引导语/提问
2. 材料分发与说明
3. 【元认知节点】引导反思："在开始之前，先想想你预测会发生什么？"
4. 过程引导与追问
5. 【元认知节点】中途检查："和你预测的一样吗？哪里不一样？"
6. 总结与过渡

*学生活动*：
1. 观察/操作/讨论
2. 记录数据/填写学习单（含反思提示）
3. 分享发现/展示成果
```

## 元认知检查清单

- [ ] 活动前是否有"计划"环节（预测、设定目标、选择策略）？
- [ ] 活动中是否有"监控"节点（检查理解、识别困惑）？
- [ ] 活动后是否有"评估+调整"环节（反思方法、规划改进）？
- [ ] 反思提示是否具体（不是"反思一下"，而是具体的问题）？
- [ ] 元认知活动是否替换了低认知活动（而不是额外增加时间）？
- [ ] 是否提供了出声思考的示范（特别是对低龄儿童）？
- [ ] 自我提问清单是否适合目标年龄（低龄用图示，高龄用文字）？

## 年龄适配

| 年龄段 | 元认知策略 | 示例 |
|--------|-----------|------|
| **2-7岁** | 简单反思提问 | "你发现了什么？" "这和刚才有什么不一样？" |
| **7-11岁** | 反思卡 + 出声思考 | "我预测……因为……" "我最惊讶的是……" |
| **11岁+** | 自我提问清单 + 策略评估 | "我用的方法有效吗？" "下次我会怎么做 differently？" |
