# 准确性保障机制 (Accuracy Assurance)

本文档定义确保活动方案科学准确性和教育有效性的多重保障机制。

## 知识来源验证

### 1.1 权威来源分级

**Tier 1 - 最高优先级（直接引用）：**
- 同行评审的科学期刊（通过 arXiv、scholar、知网检索验证）
- 权威教科书（如高中/大学标准教材）
- 知名科研机构官网（中科院、NASA、CERN等）
- 国际科学教育标准（NGSS、IB等）
- **经过完整验证流程的学术论文**（含五类幻觉检测、摘要获取、溯源标注）

**Tier 2 - 高优先级（参考使用）：**
- 知名科普作者/机构的内容
- 权威博物馆/科技馆的教育资料
- 经过验证的教育资源库

**Tier 3 - 需交叉验证：**
- 一般网络资源
- AI 生成内容（需人工核实）
- 社交媒体内容

### 1.2 知识验证流程

```
概念提出 → 来源检索（kimi_search + arXiv/scholar/知网） → 交叉验证（多源比对 + 五类幻觉检测） → 准确性评级 → 输出标注
```

**标注规范：**
- ✅ 已验证：有多个 Tier 1 来源支持
- ⚠️ 简化表述：为教学目的简化，可能有细微不严谨
- ❓ 待确认：缺乏足够来源支持，建议人工核实

## 教育适配性验证

### 2.1 认知发展匹配

根据皮亚杰认知发展阶段检查内容适配性：

| 阶段 | 年龄 | 特点 | 适配策略 |
|-----|------|------|---------|
| 前运算 | 2-7岁 | 直觉思维，难以抽象 | 具体实物操作，故事化 |
| 具体运算 | 7-11岁 | 逻辑思维，需具体支持 | 动手实验，具体例子 |
| 形式运算 | 11岁+ | 抽象思维，假设推理 | 概念讨论，设计实验 |

### 2.2 最近发展区评估

评估活动是否在参与者能力可及范围内：

```
已掌握知识 ← 最近发展区 → 需要脚手架支持
     ↑                           ↓
  太简单                        太难
  (无聊)                        (挫败)
```

**评估标准：**
- [ ] 前置知识是否在目标年龄段已学
- [ ] 新内容是否可通过引导理解
- [ ] 是否有足够的支持（提示、示例、脚手架）
- [ ] 成功标准是否可达

## 多轮验证机制

### 3.1 第一关：AI 自我校验

生成过程中进行：
- 概念定义检查
- 逻辑一致性检查
- 计算准确性检查
- 单位换算检查
- **文献检索检查**：涉及前沿/争议/精确数据的主题，是否已完成文献检索？
- **引用验证检查**：每篇引用文献是否通过五类幻觉检测？

## 不确定性处理

### 4.1 科学前沿内容

对于尚无定论的科学问题：
- 明确标注"科学界正在研究中"
- 介绍不同理论/假说
- 强调科学探索的开放性

### 4.2 简化与准确性的平衡

**可接受的简化：**
- 省略次要因素（如忽略空气阻力）
- 使用定性描述代替精确公式
- 使用类比（需注明是类比）

**不可接受的简化：**
- 改变因果关系
- 引入根本性错误
- 忽略关键安全因素

### 4.3 标注规范

在方案中使用以下标注：

| 标注 | 含义 | 示例 |
|-----|------|------|
| 🔬 | 科学事实 | 地球绕太阳公转 |
| 📐 | 简化模型 | 将地球视为完美球体 |
| 🎭 | 教学类比 | 电子像行星绕太阳 |
| ⚠️ | 常见误解 | 季节变化不是距离造成 |
| ❓ | 前沿问题 | 暗物质本质尚未明确 |

## 持续改进机制

### 5.1 反馈收集

设计反馈收集点：
- 活动实施效果
- 参与者疑问和困难
- 改进建议

### 5.2 版本管理

记录方案迭代：
```yaml
version: "1.0.0"
last_updated: "2024-XX-XX"
changelog:
  - "初始版本"
  - "修正了..."
validation_status:
  scientific: "已通过"
  educational: "待测试"
  safety: "已通过"
```

### 5.3 知识更新

定期审查：
- 科学发现是否影响本方案
- 教育标准是否有更新
- 最佳实践是否有变化

## 专家审查触发条件

以下情况建议提交专家审查：

- 涉及专业实验室操作
- 包含复杂科学争议
- 目标为竞赛/考试准备
- 参与者有特殊情况（如残障）
- 活动涉及法律法规（如野生动植物）

> 🔔 **审查建议**：本方案涉及[具体领域]，建议咨询[专家类型]进行审查。
