# 输出格式规范 (Output Schema)

本文档定义了科普教育活动方案的标准输出格式，基于科技馆优质教案模式训练提取。

## 活动方案结构

每个完整的活动方案必须包含以下部分：

### 1. 方案元数据

```yaml
方案名称: [简洁有力的标题]
适用年龄: [年龄段，如小学3-4年级/5-6年级/初中]
活动时长: [总时长，如 45分钟/60分钟/90分钟/3小时]
参与人数: [建议人数，如 15-20人/20-35人]
学科领域: [物理/化学/生物/天文/地理/工程/综合]
核心概念: [一句话概括]
活动类型: [科学探究类/综合实践活动类/社会性科学议题]
```

### 2. 课程（活动）概述 (Course Overview)

- **课程定位**：本课程是什么类型的活动，基于什么展品/情境设计
- **核心逻辑**：采用的教学模式（PBL/5E/探究式等）+ 教学理念
- **探究主题**：核心科学问题或驱动问题
- **设计理念**：如何连接学生经验与科学概念，培养哪些核心素养

### 3. 教学对象 (Target Audience)

- **针对学段**：具体年级范围
- **适宜人数**：建议人数及分组方式
- **学情分析**：
  - 已有知识基础（相关课程学习经历）
  - 认知发展阶段（皮亚杰阶段特征）
  - 能力水平（观察、实验、合作能力）
  - 兴趣特点（对该主题的生活经验和好奇心）
  - 与课标对应（如"生命系统的构成层次""技术、工程与社会"等）

### 4. 教学目标 (Learning Objectives)

采用四维目标体系（对标2022版科学课标）：

#### 4.1 科学观念
- 核心概念理解（如：蛀牙形成机制、头盔防护原理）
- 科学规律掌握（如：物质的运动与相互作用）
- 技术应用认知（如：不同材料的特性与用途）

#### 4.2 科学思维
- 思维方法（观察、比较、分类、归纳、演绎、推理、类比）
- 实验设计能力（控制变量、对比实验）
- 数据建模与问题归因能力

#### 4.3 探究实践/探究能力
- 提出问题与假设
- 设计并实施实验
- 观察、记录、分析数据
- 得出结论并交流
- 工程设计与物化能力（如适用）

#### 4.4 态度责任
- 科学态度（实事求是、严谨细致、注重实证）
- 健康/安全意识
- 社会责任感
- 文化自信/民族自豪感（如适用）
- 团队合作品质

### 5. 教学重难点 (Key Points & Difficulties)

#### 5.1 教学重点
- 知识层面：需要掌握的核心概念和原理
- 能力层面：需要培养的关键能力
- 意识层面：需要内化的价值观或态度

#### 5.2 教学难点
- 知识理解与迁移：抽象概念与具体经验的连接
- 实践操作：实验设计、变量控制、数据收集中的困难
- 成果转化：从实验证据到方案设计的转化
- 三大转化：
  - 角色转化：从被动听讲者到主动研究者
  - 问题转化：将生活疑问转化为可验证的探究课题
  - 成果转化：将科学证据转化为可执行的方案

### 6. 教学场地与教学准备 (Venue & Materials)

#### 6.1 教学场地
- 主要场地（如：科技馆活动室/展厅/教室/户外）
- 场地要求（空间大小、桌椅布置、特殊设施）

#### 6.2 教学准备
材料清单表格：

| 序号 | 材料名称 | 数量 | 单位 | 备注 |
|------|---------|------|------|------|
| 1 | | | | |

分类标注：
- **实验材料**：用于核心探究实验
- **实操材料**：用于动手制作/模型操作
- **学习单/记录表**：用于学生记录和反思
- **安全装备**：护目镜、手套等
- **辅助工具**：口腔镜、放大镜、测温计等

### 7. 教学活动设计与实施 (Activity Design & Implementation)

#### 7.1 教学活动设计思路
- **核心逻辑**：整体教学设计的理论依据和流程闭环
- **活动设计**：各环节如何衔接，如何激发兴趣→探究→建构→应用
- **角色设计**：是否采用角色扮演（如"实习医生""交通劝导员""月球建筑师"）
- **情境创设**：如何连接真实生活情境

#### 7.2 教学活动设计流程图
用 ASCII 或文字描述流程：
```
情境导入 → 提出问题 → 实验探究 → 建构认知 → 实践应用 → 总结评价
```

#### 7.3 活动步骤以及设计意图

每个阶段必须包含：

##### 阶段X：[阶段名称] (X分钟)

**阶段目标**
- 本阶段要达成的具体目标（知识/能力/态度）

**ICAP 目标档位**：[P / A / C / I]
**升档策略**：[如何从当前档位升级到更高档位]

**元认知嵌入点**：[本阶段的元认知节点]
- 活动前：...
- 活动中：...
- 活动后：...

**教学活动过程**

*教师活动*：
1. 引导语/提问
2. 材料分发与说明
3. 过程引导与追问
4. 总结与过渡

*学生活动*：
1. 观察/操作/讨论
2. 记录数据/填写学习单
3. 分享发现/展示成果
4. 提出新问题

*预期反应与应对*：
- 可能的回答/反应
- 引导员的应对策略

**设计意图**
- 为什么这样设计
- 如何支持学习目标达成
- 如何激发兴趣/降低认知负荷/促进建构

**形成性评估检查点**（每个阶段至少1个）：
- **检查方式**：观察/提问/作品检查/讨论/自评
- **检查内容**：具体观察什么、问什么问题
- **成功指标**：什么样的反应表示目标达成
- **未达标应对**：
  - 简化策略：降低难度、提供更多支架
  - 补充策略：补充讲解、提供示例
  - 延伸策略：增加挑战、拓展思考

### 8. UDL 差异化设计 × SDT 动机设计 (UDL Differentiation & Motivation)

- **多元表征（× 胜任感）**：[每个核心概念的 ≥2 种呈现方式]
  - 概念A：视觉(图示/实物) + 动觉(操作/实验)
  - 概念B：听觉(讲解/讨论) + 文字(阅读/学习单)
  - 胜任感保障：明确成功标准 / 即时反馈 / 进步可视化

- **多元表达（× 自主性）**：[每个学习目标的 ≥2 种表达选项]
  - 目标1：口头解释 或 填写记录表 或 制作模型
  - 目标2：小组讨论 或 绘制设计图 或 编写方案
  - 自主性保障：任务选择 / 方法选择 / 顺序选择 / 角色选择

- **多元参与（× 归属感）**：[提供的参与方式选择]
  - 路径选择：[A实验 / B观察 / C调研]
  - 难度选择：[基础版 / 进阶版 / 挑战版]
  - 协作模式：[个人 / 配对 / 小组 / 全班]
  - 归属感保障：不可替代角色 / 互评机制 / 集体作品

- **无障碍设计**：
  - 视觉替代：大字版材料、高对比度图表
  - 听觉替代：手语说明、文字提示
  - 动觉替代：语音控制、辅助工具

### 9. 教学法框架 (Pedagogical Framework)

- **选择框架**：[5E / 4-Stage / PBL / Design Thinking / SSI / IBL / DIE / IADE / Guided Play]
- **选择理由**：[为什么这个框架适合本主题、目标人群、场景需求]
- **框架映射**：
  - 框架阶段1 → 对应本活动的哪个阶段
  - 框架阶段2 → 对应本活动的哪个阶段
  - ...
- **混合框架**（如适用）：[说明哪些阶段使用哪个框架]

### 10. STEM/STEAM 整合映射 (STEM/STEAM Integration)

当主题适合跨学科整合时，提供整合映射：

|------|---------------|---------|---------|
| 科学 (S) | 核心概念 | ... | ... |
| 技术 (T) | 工具/方法 | ... | ... |
| 工程 (E) | 设计挑战 | ... | ... |
| 数学 (M) | 计算/分析 | ... | ... |
| 艺术 (A) | 美学/表达 | ... | ... |

**整合问题**：[用一个真实问题驱动所有学科]

### 10.5 ICAP 认知参与层次评估 (ICAP Assessment)

**整体 ICAP 趋势**：
```
阶段1：[档位] → 阶段2：[档位] → 阶段3：[档位] → 阶段4：[档位]
```

**各阶段档位与升档策略**：
| 阶段 | 档位 | 升档策略 |
|------|------|---------|
| 阶段1 | P/A/C/I | ... |
| 阶段2 | P/A/C/I | ... |

**关键升档节点**：
- [节点1]：从...升级到...，策略是...
- [节点2]：从...升级到...，策略是...

### 10.6 明暗线对齐检查 (Visible vs. Hidden Line)

| 环节 | 明线（学生体验） | 暗线（目标指向） | 对齐检查 |
|------|----------------|----------------|---------|
| 导入 | ... | ... | ✅ 对齐 / ⚠️ 需调整 |
| 任务1 | ... | ... | ✅ 对齐 / ⚠️ 需调整 |
| 任务2 | ... | ... | ✅ 对齐 / ⚠️ 需调整 |
| 总结 | ... | ... | ✅ 对齐 / ⚠️ 需调整 |

**调整说明**：如有 ⚠️ 标记，说明该环节的"有趣"未有效服务教学目标，需调整。

### 11. 评估方式 (Assessment)

#### 11.1 形成性评估检查点

每个学习目标对应至少一个检查点，嵌入活动流程中：

| 检查点 # | 对应目标 | 检查方式 | 检查内容 | 成功指标 | 未达标应对 |
|---------|---------|---------|---------|---------|----------|
| 1 | 目标1 | 观察/提问 | ... | ... | 简化/补充/延伸策略 |
| 2 | 目标2 | 作品检查 | ... | ... | ... |

#### 11.2 总结性评估
- **评估工具**：学习单/实验报告/设计方案/展示汇报
- **评价标准**：基于学习目标的评价标准
- **UDL 评估替代方案**：口头汇报、视频制作、模型展示、小组表演

#### 11.3 参与度评估
- **观察指标**：动手操作频率、提问次数、小组互动质量
- **自评量表**：参与者用1-3星自评参与度和理解度

### 12. 应急预案 (Contingency Plans)

- **材料不足**：替代方案（如鸡蛋替代牙齿模型）
- **实验失败**：解释和补救（如对比实验不明显时的分析）
- **时间超出**：可删减的环节
- **参与者不感兴趣**：调整策略（增加竞赛/游戏化元素）
- **安全问题**：紧急处理流程
- **户外调研受阻**：室内模拟方案

### 13. 参考资料 (References)

- **课标对应**：与2022版科学课标的具体对应
- **延伸阅读**：相关书籍、文章、视频
- **标准文件**：如 GB 24429（头盔安全标准）
- **验证标注**：引用文献的验证状态（✅ VERIFIED / ⚠️ 待确认）

### 14. 附件 (Appendices)

- 学习单/记录表模板（含前测/后测问卷）
- 实验观察记录表
- 设计草图/方案模板
- PPT/海报设计建议
- 背景阅读材料（给引导员）
- 实验操作视频链接

### 15. 效果评估与辐射推广 (Evaluation & Outreach)

#### 15.1 效果评估
- **学生感受**：成就感、兴趣变化、民族自豪感/文化自信
- **知识传递**：概念理解程度、科学方法掌握情况
- **能力发展**：探究能力、工程设计能力、合作能力
- **评估工具**：学习单分析、课堂观察记录、学生自评/互评

#### 15.2 辐射推广
- **适用场景**：研学活动、校园定制课程、下乡活动、科学表演、线上直播
- **推广优势**：教具简单、成本低、便于携带、可根据对象灵活调整时长
- **改编建议**：如何根据不同学段/人数/场地调整活动

## 特色设计要素

### 角色扮演设计
当活动采用角色扮演时：
- **角色设定**：具体角色名称和职责
- **情境创设**：如何让学生代入角色
- **任务驱动**：角色需要完成的具体任务
- **情感连接**：角色与真实生活的连接

### 对比实验设计
当活动包含对比实验时：
- **变量控制**：明确自变量、因变量、控制变量
- **对照组设置**：清水组/空白组的标准设置
- **观察记录**：标准化的记录表格
- **安全注意**：实验操作的安全提示

### 社会调研设计
当活动包含社会调研时：
- **调研工具**：观察记录表、访谈提纲
- **安全预案**：户外活动的安全措施
- **数据处理**：如何整理和分析调研数据
- **伦理注意**：保护受访者隐私

### 工程设计流程
当活动包含工程设计时：
- **需求分析**：明确设计约束条件
- **方案设计**：草图绘制、材料选择
- **原型制作**：动手搭建/制作
- **测试迭代**：测试方案、收集反馈、改进优化
- **展示评价**：成果展示、接受质疑
