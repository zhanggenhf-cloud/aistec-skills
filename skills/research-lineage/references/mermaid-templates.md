# Mermaid 图表模板参考

## 时间线（Gantt）

```mermaid
gantt
    title 研究发展时间线
    dateFormat YYYY
    section 奠基期
    理论建立    : 1970, 1980
    实验验证    : 1975, 1985
    section 突破期
    技术突破    : 1990, 1995
    section 分化期
    分支A      : 1995, 2005
    分支B      : 2000, 2010
    section 当前
    前沿研究    : 2020, 2025
```

## 脉络图（Flow/Graph）

```mermaid
graph TD
    A[核心问题] --> B[早期理论]
    B --> C[实验验证]
    C --> D[技术突破]
    D --> E[分支1: 应用方向]
    D --> F[分支2: 理论深化]
    D --> G[分支3: 跨学科拓展]
    E --> H[当前应用1]
    E --> I[当前应用2]
    F --> J[当前理论前沿]
    G --> K[跨学科融合]
```

## 对比分支（Subgraph）

```mermaid
graph LR
    subgraph 理论分支
    A1[理论1] --> A2[理论2]
    A2 --> A3[当前理论]
    end
    
    subgraph 实验分支
    B1[实验1] --> B2[实验2]
    B2 --> B3[当前实验]
    end
    
    subgraph 应用分支
    C1[应用1] --> C2[应用2]
    C2 --> C3[当前应用]
    end
    
    A3 --> D[融合前沿]
    B3 --> D
    C3 --> D
```

## 时间序列（Timeline，较新语法）

```mermaid
timeline
    title 研究发展简史
    19XX : 起源
         : 奠基论文
    20XX : 技术突破
         : 大规模应用
    20XX : 当前前沿
         : 开放问题
```

## 使用原则

1. **节点命名**：使用简短、准确的中文或英文术语
2. **连线标注**：在关键连线上添加说明文字，如 `--> |"关键转折"| B`
3. **颜色区分**：使用 subgraph 分组，区分不同分支或时期
4. **避免过度**：节点数量控制在 15 个以内，复杂脉络拆分成多个子图
