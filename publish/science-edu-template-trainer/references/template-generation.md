# 模板生成方法论

本文档定义从多个活动方案分析结果中提取通用模板的方法。

## 模板生成流程

### 阶段一：数据汇总

收集所有方案的分析结果，进行聚类：

```
输入: [方案分析1, 方案分析2, ..., 方案分析N]
      ↓
按维度分组统计
      ↓
输出: 各维度的分布统计
```

**汇总统计项：**

1. **结构覆盖率**
   - 每个章节出现的频率
   - 识别"几乎必有的章节"
   - 识别"可选章节"

2. **数值分布**
   - 时长分布（众数、中位数、范围）
   - 年龄范围常见模式
   - 参与人数常见区间

3. **模式识别**
   - 最常见的教学流程结构
   - 高频使用的互动方式
   - 标准的评估方式组合

### 阶段二：最佳实践提取

从高质量方案中提取优秀元素：

**识别标准：**
- 结构完整性得分 > 0.8
- 内容深度适中且年龄适配
- 实用性评估为 high
- 具有创新性设计

**提取内容：**
- 优秀的话术示例
- 有效的过渡方式
- 巧妙的互动设计
- 清晰的安全提示写法

### 阶段三：通用模式定义

定义模板的核心结构：

**1. 必须章节 (Required Sections)**
出现频率 > 80% 的章节

**2. 推荐章节 (Recommended Sections)**
出现频率 50-80% 的章节

**3. 可选章节 (Optional Sections)**
出现频率 < 50% 的章节

### 阶段四：默认值确定

为各字段设定默认值：

| 字段 | 默认值策略 | 示例 |
|-----|-----------|------|
| 时长 | 众数或中位数 | "60分钟" |
| 年龄 | 常见区间 | "8-12岁" |
| 人数 | 标准教室规模 | "15-30人" |
| 四阶段时间分配 | 平均值 | 引入15%/探索35%/讨论25%/应用25% |

### 阶段五：约束规则制定

制定模板使用的约束：

**结构约束：**
- 必须章节不可省略
- 推荐章节建议保留
- 章节顺序建议遵循

**内容约束：**
- 学习目标数量：3-5个
- 材料清单格式：表格
- 安全提示位置：摘要后、流程中

**格式约束：**
- 标题层级：#/##/###
- 列表格式：- 或 1.
- 强调方式：**粗体**

## 模板演进机制

### 版本管理

```yaml
template:
  name: "科普教育活动方案标准模板"
  version: "1.0.0"
  generated_from: "N个活动方案分析"
  generated_date: "2024-XX-XX"
  
base_profile:
  target_institution: "科技馆/学校/科普中心"
  typical_duration: "45-90分钟"
  typical_group: "15-30人"
  
structure:
  required: ["基本信息", "学习目标", "活动流程", "材料清单", "安全提示"]
  recommended: ["活动摘要", "背景知识", "评估要点", "应急预案"]
  optional: ["场地要求", "人员配置", "参考资料"]
  
constraints:
  min_learning_objectives: 3
  max_learning_objectives: 5
  must_have_four_stages: true
  material_list_format: "table"
```

### 适应性调整

根据具体应用场景调整模板：

| 场景 | 调整策略 |
|-----|---------|
| 博物馆活动 | 强调展品连接、参观流程 |
| 学校课堂 | 强调课程标准对齐、作业设计 |
| 户外探索 | 强调安全预案、天气应对 |
| 短期工作坊 | 简化结构、强调动手 |
| 系列课程 | 增加前后连接、进度追踪 |

### 反馈驱动的模板优化

收集模板使用反馈，持续改进：

**反馈收集点：**
- 模板是否容易填写
- 哪些字段经常困惑
- 缺失的常用内容
- 不必要的冗余内容

**优化周期：**
- 每次分析新方案时对比现有模板
- 识别新兴的最佳实践
- 定期发布模板更新

## 模板输出格式

生成的通用模板：

```markdown
# 科普教育活动方案模板

## 模板元数据
- **版本**: 1.0.0
- **生成来源**: 基于N个活动方案分析
- **适用场景**: 科技馆/学校/科普中心
- **典型时长**: 45-90分钟
- **典型人数**: 15-30人

## 结构规范

### 必须章节（不可省略）
1. 基本信息
2. 学习目标
3. 活动流程
4. 材料清单
5. 安全提示

### 推荐章节（建议保留）
1. 活动摘要
2. 背景知识
3. 评估要点
4. 应急预案

### 可选章节（按需添加）
1. 场地要求
2. 人员配置
3. 参考资料

## 各章节规范

### 基本信息
| 字段 | 要求 | 默认值 |
|-----|------|--------|
| 方案名称 | 必填 | - |
| 适用年龄 | 必填 | 8-12岁 |
| 活动时长 | 必填 | 60分钟 |
| 参与人数 | 必填 | 15-30人 |
| 学科领域 | 必填 | - |
| 核心概念 | 必填 | - |

### 学习目标
- 数量：3-5个
- 格式："参与者能够..."
- 覆盖：知识/技能/态度

### 活动流程
必须包含四阶段：
1. 引入（10-15%时长）
2. 探索（30-40%时长）
3. 讨论（25-30%时长）
4. 应用（15-25%时长）

每阶段包含：目标、内容、话术建议

### 材料清单
表格格式：
| 材料名称 | 数量 | 规格/要求 | 获取渠道 | 预估成本 |

### 安全提示
- 风险识别
- 预防措施
- 应急处理

## 格式规范

### Markdown 标准
- 一级标题: `#`
- 二级标题: `##`
- 三级标题: `###`
- 列表: `-` 或 `1.`
- 强调: `**粗体**`
- 引用: `>`

### 内容风格
- 正式程度：半正式
- 人称：第二人称（引导员视角）
- 句式：祈使句为主，适当使用问句

## 质量检查清单

使用前自检：
- [ ] 所有必须章节已填写
- [ ] 学习目标符合SMART原则
- [ ] 四阶段时间分配合理
- [ ] 材料清单完整可执行
- [ ] 安全提示充分明确
- [ ] 科学内容准确无误
```
