# 活动方案分析框架

本文档定义分析科普教育活动方案的结构化框架。

## 分析维度

### 1. 元数据分析 (Metadata)
提取方案的基础信息：

| 字段 | 描述 | 示例值 |
|-----|------|--------|
| 方案名称 | 标题 | "彩虹的秘密" |
| 适用年龄 | 目标年龄段 | "8-12岁" |
| 活动时长 | 总时长 | "60分钟" |
| 参与人数 | 建议人数 | "15-30人" |
| 学科领域 | 所属学科 | "物理/光学" |
| 核心概念 | 一句话概括 | "光的色散现象" |
| 活动类型 | 主要形式 | "动手实验" |

### 2. 结构分析 (Structure)

识别方案包含的章节：

```
标准结构清单：
□ 方案标题
□ 基本信息（年龄/时长/人数）
□ 活动摘要/简介
□ 学习目标
□ 背景知识/科学原理
□ 活动流程/步骤
□ 材料清单
□ 场地要求
□ 安全提示
□ 评估方式
□ 应急预案
□ 参考资料
```

记录每个章节：
- 是否存在
- 详细程度（简略/适中/详细）
- 内容质量（低/中/高）

### 3. 教学流程分析 (Pedagogical Flow)

识别教学阶段及其特征：

| 阶段 | 识别关键词 | 典型时长占比 |
|-----|-----------|-------------|
| 引入 (Hook) | 开场、问题、故事、现象 | 10-15% |
| 探索 (Exploration) | 实验、观察、操作、制作 | 30-40% |
| 讨论 (Discussion) | 解释、原理、讨论、总结 | 25-30% |
| 应用 (Application) | 拓展、应用、延伸、挑战 | 15-25% |

分析维度：
- 阶段完整性（是否四阶段齐全）
- 时间分配合理性
- 阶段间过渡方式
- 参与方式（个体/小组/全体）

### 4. 内容深度分析 (Content Depth)

评估科学内容的处理方式：

**概念处理层级：**
- **L1 现象描述**：观察到什么
- **L2 原理说明**：为什么会这样（定性）
- **L3 定量关系**：涉及什么公式/数值
- **L4 拓展联系**：与哪些其他概念相关

**年龄适配评估：**
- 是否匹配认知发展阶段
- 是否存在超纲内容
- 是否需要前置知识

### 5. 互动设计分析 (Interaction Design)

分析学习者参与方式：

| 互动类型 | 描述 | 频率 |
|---------|------|------|
| 动手操作 | 实验、制作 | 次 |
| 观察记录 | 观察现象、填写表格 | 次 |
| 讨论交流 | 小组讨论、分享 | 次 |
| 游戏竞赛 | 规则游戏、竞赛 | 次 |
| 角色扮演 | 情境模拟 | 次 |
| 多媒体 | 视频、动画 | 次 |

### 6. 评估体系分析 (Assessment)

识别评估要素：

- **评估时机**：形成性/总结性
- **评估方式**：观察/问答/作品/测试
- **评估维度**：知识/技能/态度
- **成功标准**：如何定义活动成功

### 7. 语言风格分析 (Language Style)

分析文本特征：

| 维度 | 描述 | 示例 |
|-----|------|------|
| 正式程度 | 学术/半正式/口语化 | |
| 叙事视角 | 第一/第二/第三人称 | |
| 句式特点 | 长短句比例、问句使用 | |
| 专业术语密度 | 术语使用频率 | |
| 引导语风格 | 指令式/启发式/对话式 | |

### 8. 实用性分析 (Practicality)

评估可执行性：

- 材料获取难度（易/中/难）
- 场地要求特殊性
- 人员配置要求
- 时间估算现实性
- 安全措施完整性
