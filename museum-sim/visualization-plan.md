## 2. 核心可视化组件

## 3. 技术栈推荐

### 前端
| 组件 | 技术选型 | 用途 |
|------|----------|------|
| 地图渲染 | **PixiJS** / Three.js | 2D/3D 实时渲染 |
| 热力图 | **heatmap.js** | WebGL 热力图 |
| 网络图 | **D3.js** / Cytoscape.js | 社交网络可视化 |
| UI框架 | **React** + Tailwind | 界面组件 |
| 实时通信 | **Socket.IO** | WebSocket连接 |

### 后端
| 组件 | 技术选型 | 用途 |
|------|----------|------|
| 模拟引擎 | **Python** + asyncio | Agent行为模拟 |
| LLM接口 | OpenAI API / Claude | Agent决策 |
| 数据库 | **TimescaleDB** | 时序数据存储 |
| 缓存 | **Redis** | 实时状态缓存 |
| API服务 | **FastAPI** | REST + WebSocket |
